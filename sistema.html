Perfis de acesso

Regras aplicadas no painel.

AdministradorAcesso total: clientes, valores, custos, caixa, pagamentos, gráficos financeiros, relatórios, usuários, configurações do sistema e parâmetros do site.
FuncionárioAcesso a cadastro e execução: clientes, serviços, tarefas e criativos. Não visualiza contrato, pagamentos, caixa, custos, relatórios financeiros ou configurações administrativas.
ClienteAcesso somente ao próprio cadastro: serviços contratados, valor contratado, pagamentos do mês, caixa disponível, utilização detalhada e progresso das entregas.
Importante: esta versão foi preparada para GitHub Pages e usa login local para demonstração. Para segurança real e acesso de vários dispositivos/clientes, publique o mesmo front-end com Firebase Authentication + Firestore.
